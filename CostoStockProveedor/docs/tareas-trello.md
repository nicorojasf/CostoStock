# Tablero Trello sugerido
Columnas: **Por hacer · En progreso · En revisión · Hecho**.
Crea una tarjeta por ítem, asígnala a una persona y nombra la tarjeta en el commit/PR (ej: `feat: valida RUT (#12)`).

## App de Proveedores
- [ ] Crear repositorio, ramas y tablero
- [ ] Base de datos SQLite (sellers, products) y DAOs
- [ ] Validadores (RUT, teléfono, contraseña, precio, stock) + tests unitarios
- [ ] Registro y login de proveedores
- [ ] Perfil: datos, edición y cierre de sesión
- [ ] Recurso nativo: cámara (foto de perfil y de productos, con permisos)
- [ ] Recurso nativo: vibración (feedback háptico)
- [ ] Mis publicaciones: lista, filtros, búsqueda, pausar y eliminar
- [ ] Asistente de publicación (4 pasos) con validación por paso
- [ ] Edición de publicaciones
- [ ] Animaciones (transiciones, progreso, errores, contadores)
- [ ] Documentar contrato de datos con la app de cliente
- [ ] README final y entrega en AVA
